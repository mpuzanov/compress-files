# compress-files

Консольная утилита принимает файл или каталог. Если указан каталог, она рекурсивно ищет в нём файлы `.pdf`, `.jpg` и `.jpeg`. Если указан файл, обрабатывается только он. Файлы размером **строго больше 1 МБ** утилита пытается сжать и заменяет оригинал только тогда, когда результат меньше исходного файла.

Перед заменой сжатый файл проверяется. Замена выполняется через временную резервную копию в том же каталоге; при ошибке оригинал восстанавливается.

Все действия одновременно выводятся в консоль и дописываются в `compress-files.log` рядом с программой. Каждая строка содержит дату и время. Другой путь можно задать параметром `-log-file`.

## Требования

- Windows, Linux или macOS;
- для PDF должен быть установлен [Ghostscript](https://www.ghostscript.com/);
- для JPG внешние программы не нужны.

Если Ghostscript не добавлен в `PATH`, его можно указать параметром `-ghostscript`.

## Сборка

```powershell
go build -o compress-files.exe .
```

## Запуск

```powershell
.\compress-files.exe "D:\Документы"
```

Обработка одного конкретного файла:

```powershell
.\compress-files.exe "D:\Документы\скан.pdf"
```

Сначала рекомендуется проверить ожидаемый результат без замены файлов:

```powershell
.\compress-files.exe -dry-run "D:\Документы"
```

Параметр `-recursive` применяется только при обработке каталога.

Основные параметры:

```text
-min-size 1048576       минимальный размер в байтах (по умолчанию 1 МБ)
-jpeg-quality 75        качество JPEG от 1 до 100
-pdf-quality ebook      screen, ebook, printer, prepress или default
-recursive=true         поиск во вложенных каталогах
-ghostscript <путь>     явный путь к gswin64c.exe или gs
-dry-run                проверка без замены оригиналов
-log-file <путь>        другой путь к файлу журнала
```

Профиль PDF `ebook` обычно даёт разумный баланс между размером и качеством. `screen` сжимает сильнее, `printer` и `prepress` сохраняют более высокое качество.

## Обработка JPG

JPG перекодируется стандартными средствами Go без изменения геометрического размера. EXIF-данные (включая ориентацию снимка) и цветовой профиль ICC сохраняются. Остальные необязательные служебные сегменты JPEG могут быть удалены.
